# uploads（画像の受け取り口）

ここに画像をアップロードしてから、**Actions タブ →「画像を登録する」→ Run workflow** を実行すると、
画像が WebP に変換されて作品フォルダの正しい場所に置かれ、設定ファイル（JSON）にも反映されます。
登録が終わった画像は、このフォルダから自動で消えます。

1. このフォルダを開いた状態で **Add file → Upload files** から画像（PNG・JPEG・WebP）をアップロードする
2. **Commit changes** を押す
3. **Actions** タブ →「画像を登録する」→ **Run workflow** で、作品ID・種類・名前などを入れて実行する

詳しくは [作品の追加方法](../docs/作品の追加方法.md) の「画像登録ボタン」を見てください。
