# ひな形フォルダ

`story_template` は、新しい作品フォルダのひな形です（設定ファイルのみ・中身は空。画像・音声は入っていません）。

## 新しい作品フォルダの作り方

**おすすめ：** リポジトリの **Actions** タブ →「新しい作品フォルダを作る」→ **Run workflow** で作品ID を入力すると、
このひな形が `public/stories/作品ID/` に自動でコピーされます。

手作業でコピーする場合は、`story_template` フォルダ（`templates` フォルダではなく）を `public/stories` の中にコピーし、
フォルダ名を作品ID に変えてください。

詳しくは [作品の追加方法](../docs/作品の追加方法.md) を見てください。
