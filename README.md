# ClaudeGame006

Web小説試し読みノベルゲーム

複数のWeb小説作品の第1話や見せ場を、ビジュアルノベル形式で楽しめるゲームアプリです。
React + TypeScript + Vite で作成し、GitHub Pages で公開します（Android 版は将来 Capacitor で対応予定）。

## 開発コマンド

```bash
npm install      # 初回のみ
npm run dev      # 開発サーバー起動（表示されたURLをブラウザで開く）
npm run check    # 全作品のシナリオ・設定・素材をチェック（公開前に必ず実行される）
npm test         # シナリオ読み取り機能のテスト
npm run build    # チェック＋本番ビルド（dist/ に出力）
npm run preview  # ビルド結果の確認
```

`npm run check` で問題が見つかると、`main` にプッシュしても公開は行われません。
GitHub の **Actions** タブで赤い × が付いた実行を開くと、「どのファイルの何行目に何の問題があるか」が日本語で表示されます。

## フォルダ構成

```
public/stories/          … 作品データ（ゲーム本体のコードとは独立）
  catalog.json           … 作品一覧（表示する作品IDを並べる）
  novel_001/
    info.json            … 作品情報（タイトル・作者・あらすじ・原作URL・エピソード一覧）
    characters.json      … キャラクター情報（表示名・立ち絵画像・大きさ）
    assets.json          … 背景などの「名前」と「画像ファイル名」の対応
    cover.svg            … 表紙画像
    scenarios/           … シナリオ（日本語テキスト .txt）
    backgrounds/         … 背景画像
    characters/          … 立ち絵画像
    stills/              … スチル画像
    audio/               … BGM・効果音
src/                     … ゲーム本体
scripts/                 … 公開前チェックとテスト
.github/workflows/       … GitHub Pages 自動デプロイ設定
```

## 作品の追加方法（概要）

1. `public/stories/novel_001` をコピーして新しいフォルダ（例：`novel_003`）を作る
2. `info.json` の `id` をフォルダ名と同じにし、タイトルなどを書き換える
3. 表紙画像を入れ、`info.json` の `cover` にファイル名を書く
4. `public/stories/catalog.json` の `stories` に作品ID を追加する

ゲーム本体のソースコードを編集する必要はありません。

### info.json の書き方

```json
{
  "id": "novel_001",
  "title": "作品タイトル",
  "author": "作者名",
  "cover": "cover.png",
  "summary": "作品一覧に表示する短い紹介文",
  "synopsis": "作品詳細に表示するあらすじ（\n で改行）",
  "genre": "青春・日常",
  "originalUrl": "https://原作掲載ページのURL",
  "episodes": [
    { "id": "episode_01", "title": "第1話 タイトル", "file": "episode_01.txt", "order": 1 },
    { "id": "episode_02", "title": "第2話 タイトル", "file": "episode_02.txt", "order": 2 }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `id` | フォルダ名と同じにする |
| `cover` | 作品フォルダに入れた表紙画像のファイル名（縦長 5:7 程度がきれいに表示されます） |
| `originalUrl` | 「原作を読む」「原作の続きを読む」ボタンのリンク先 |
| `episodes` | エピソード一覧。`file` は `scenarios` フォルダ内のシナリオファイル名、`order` は表示順（小さい順） |

**エピソードを追加するとき**は、`scenarios` フォルダにシナリオ（.txt）を入れ、`episodes` に1行追加するだけです。

### characters.json の書き方

```json
{
  "characters": [
    { "id": "sakura", "name": "サクラ", "image": "sakura.png", "height": 85 },
    { "id": "ruri", "name": "ルリ", "image": "ruri_bust.png", "height": 55 }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `id` | 半角英数字の識別名 |
| `name` | シナリオで書く名前（例：`#キャラ画像 サクラ`） |
| `image` | `characters` フォルダに入れた画像ファイル名（全身・バストアップどちらでも可。透過PNG/WebP推奨） |
| `height` | 画面の高さに対する立ち絵の高さ（%）。省略すると 85。全身なら 80〜90、バストアップなら 50〜60 が目安 |
| `offsetX` / `offsetY` | 位置の微調整（%）。省略可。`offsetX` はプラスで右、`offsetY` はプラスで下へずれる |

### assets.json の書き方

```json
{
  "backgrounds": {
    "教室": "classroom.png",
    "廊下": "corridor.png"
  },
  "stills": {
    "夕焼け": "sunset.png"
  }
}
```

左がシナリオで書く名前（例：`#背景 教室`、`#スチル 夕焼け`）、右がそれぞれ `backgrounds`・`stills` フォルダに入れたファイル名です。

## シナリオの書き方（概要）

シナリオは `scenarios` フォルダに UTF-8 のテキストファイル（.txt）で書きます。
（詳しい説明書は Phase 6 で作成します）

```
#背景 教室

#キャラ画像 サクラ

#台詞 サクラ
「どうしたの？」

#モノローグ
　今日はいい天気だ。

#キャラ画像 なし
#スチル 夕焼け

私たちは、沈んでいく夕日を見つめていた。

#終了
```

| コマンド | 意味 |
|---|---|
| `#背景 名前` | 背景を表示 |
| `#キャラ画像 キャラ名` | 立ち絵を中央に表示（`#キャラ画像 なし` で全員消す） |
| `#キャラ画像左 キャラ名` / `#キャラ画像右 キャラ名` | 立ち絵を左／右に表示（`なし` でその位置を消す） |
| `#台詞 キャラ名` | 次のコマンドまでの文章を、そのキャラのセリフとして表示 |
| `#モノローグ` | 次のコマンドまでの文章を、名前なしの地の文として表示 |
| `#スチル 名前` | 一枚絵を表示（立ち絵は隠れる）。`#スチル なし` で元に戻す |
| `#終了` | エピソードを終える |
| `#表情` `#BGM` `#効果音` | 書いても大丈夫ですが、効果は Phase 5 で実装します |

書き方のルール：

- コマンドの後ろの文章は、次のコマンドまでが **1回のタップで表示される1つの文章** になります。途中の空行もそのまま表示されます。
- コマンドを書かずに書いた文章は、地の文（名前なし）になります。
- 「」はゲームが自動で付けないので、セリフには自由に「」を書いてください。
- 行頭の全角スペース（字下げ）はそのまま表示されます。
- `#` や `＃` はどちらでもコマンドとして使えます。コマンドと名前の間は半角・全角スペースのどちらでも構いません。
- 文中の `#` は普通の文字として表示されます。**行頭に `#` を書きたいとき**は `\#` と書いてください（例：`\#今日の日直`）。
- 知らないコマンドや、登録されていないキャラ名・背景名・スチル名を書くと、ゲーム画面とチェックでエラーが表示されます。
- `#台詞` の名前は、立ち絵が登録されていない名前（例：「店員」「？？？」）でも使えます。

## GitHub Pages の公開設定（最初に1回だけ）

1. GitHub でこのリポジトリを開く
2. 上部の **Settings** をクリック
3. 左メニューの **Pages** をクリック
4. **Build and deployment** の **Source** を **GitHub Actions** に変更する
5. `main` ブランチにプッシュすると自動でビルド・公開される
   （進行状況は **Actions** タブで確認できます。緑のチェックが付けば公開完了）

公開URL: https://caitakenchikuclub.github.io/ClaudeGame006/

> リポジトリ名を変更した場合は `vite.config.ts` の `base` も同じ名前に変更してください。
