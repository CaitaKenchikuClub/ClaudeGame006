# 背景画像の作り方（ChatGPT）

ChatGPT の画像生成で、このゲーム用の背景画像を作るためのプロンプト集です。
立ち絵の作り方は [キャラ画像の作り方（ChatGPT）](キャラ画像の作り方（ChatGPT）.md) を見てください。

> ⚠ **使う前に必ず確認してください**
> - 原作の舞台を AI で画像にすること、その画像をゲームで使うことについて、**原作者（権利者）の許可** を得てください
> - 他の作家・作品の絵柄や、実在の建物・企業のロゴなどをまねる指定はしないでください

---

## 1. 準備するもの

- どんな場所か（例：王城の中庭、放課後の教室、港町の市場）
- 時間帯・天気（例：晴れた昼、夕方、雨の夜）
- あれば参考になる画像（原作の挿絵、作品の表紙、キャラクターの立ち絵など。絵柄をそろえるのに役立ちます）

---

## 2. プロンプト（コピーして使う）

下のプロンプトを ChatGPT に貼り付けて送ります。書き換えるのは、一番上の **【入力】の3行だけ** です。
作品の表紙や立ち絵の画像を一緒に添付すると、絵柄をそろえやすくなります（添付しなくても大丈夫です）。

```
【入力】
- 場所の説明：【フィオーレ王国の王城の中庭。噴水と花壇があり、奥に城の回廊が見える】
- 時間帯・天気：【晴れた昼】
- 雰囲気：【明るく穏やか】

【入力】の場所を、スマホ向けビジュアルノベルゲームの背景画像として1枚描いてください。

【条件】
- 縦長の画像（縦横比 2:3、例：1024×1536）
- 人物・動物・キャラクターは描かない（背景だけ）
- 文字・看板の文字・ロゴ・サイン・枠線は入れない
- 視点は、その場所に立った人の目の高さ。正面を向いたまっすぐな構図（極端な見上げ・見下ろし・広角のゆがみは避ける）
- 大事なもの（建物・窓・噴水など、場所が分かるもの）は、画像の左右中央の約70%の範囲に入れる（スマホでは左右の端が少し切れて表示されるため）
- 画像の下から約3分の1はメッセージウィンドウで隠れるので、床や地面など、隠れても困らないものにする
- 画面の中央あたりには人物が立つので、物を置きすぎず、すっきりさせる
- 画風：日本のアニメ・ギャルゲー風の背景美術。手描き風の丁寧な塗り
- 画像全体にピントが合った背景にする（ぼかさない）
- 手前に立つ人物が目立つように、色は少しやわらかめ、明暗の差は強すぎないようにする
- 画像が添付されていれば、その絵柄・色合いにそろえる

【出力形式】
- 生成できたら、WebP 形式（品質 85 程度）に変換して、ダウンロードできるようにしてください
- ファイル名は「background.webp」にしてください
- WebP に変換できない場合は PNG のままで構いません
```

> 💡 WebP への変換は、ChatGPT がファイルを作る機能を使って行います。利用状況によっては変換されず PNG のまま渡されることがあります。その場合は「この画像を WebP に変換してダウンロードできるようにしてください」と送るか、[WebP 変換ツール](https://caitakenchikuclub.github.io/ClaudeGame006/tools/webp-converter.html) で変換してください（画質は「背景向け（85）」がおすすめです）。

---

## 3. 同じ場所の時間違い・天気違いを作る

同じ会話の中で次のように送ると、構図をそろえたまま別の時間帯の背景を作れます。

```
今の背景と同じ場所・同じ構図・同じ絵柄のまま、時間帯だけ【夕方】にしたものを描いてください。
できたら WebP 形式に変換して、ダウンロードできるようにしてください。
```

`【夕方】` の部分は「夜」「雨の日」「雪の日」などに変えられます。

---

## 4. うまくいかないときの追加の指示

| うまくいかないこと | 送る文章の例 |
|---|---|
| 人物が描かれている | `人物をすべて消して、背景だけにしてください` |
| 文字や看板の文字が入っている | `文字・看板の文字・ロゴをすべて消してください` |
| 横長になっている | `縦長（縦横比 2:3）で描き直してください` |
| 大事なものが端にある | `【噴水】が画像の中央に来るように、構図を描き直してください` |
| 見上げすぎ・広角でゆがんでいる | `その場に立った人の目の高さから、まっすぐ正面を見た構図で描き直してください` |
| 背景がぼやけている | `画像全体にピントが合った、くっきりした背景にしてください` |
| 色が濃すぎて立ち絵が目立たない | `全体の色を少しやわらかく、明暗の差を少し弱くしてください` |
| 絵柄が立ち絵と合わない | `添付した立ち絵と絵柄・塗り方・色合いをそろえて描き直してください` |

## 5. ゲームに登録する

> 💡 **画像登録ボタンを使うと簡単です**：`uploads` フォルダに画像をアップロードし、Actions タブの「画像を登録する」を実行すると、WebP への変換・置き場所・設定ファイルへの反映がまとめて行われます（[作品の追加方法](作品の追加方法.md) の「画像登録ボタン」）。以下は手作業で登録する場合の説明です。

1. 画像を作品フォルダの `backgrounds/` に入れます（ファイル名は半角英数字。例：`courtyard.webp`）
2. `assets.json` の `backgrounds` に「シナリオで使う名前」と「ファイル名」を登録します（[設定ファイル作成ツール](https://caitakenchikuclub.github.io/ClaudeGame006/tools/json-generator.html) の「背景・スチル・音」タブで作れます）

```json
{
  "backgrounds": {
    "中庭": "courtyard.webp",
    "中庭（夕方）": "courtyard_evening.webp"
  }
}
```

3. シナリオで使います

```
#背景 中庭
```

> ファイルの大きさは 1枚 500KB 以下が目安です。WebP にすると、たいていこの範囲に収まります。

## 6. ゲーム画面での見え方のしくみ（参考）

- 背景は **画面全体を覆うように** 表示されます（縦横比はそのまま）
- 縦長のスマホでは画面が画像より細いため、**左右それぞれ最大 15% ほどが切れて** 表示されます（PC では 8% ほど）。大事なものを中央の約70%に入れるのはこのためです
- 画面の下から約 4 分の 1（文章が長いときは半分近く）はメッセージウィンドウが重なります
- 立ち絵は背景の手前、画面の下端に合わせて表示されます。キャラクターの顔は画面の真ん中より少し上に来ます
- 横長の画像も使えますが、左右が大きく切れてしまうので、縦長（2:3）で作るのがおすすめです
