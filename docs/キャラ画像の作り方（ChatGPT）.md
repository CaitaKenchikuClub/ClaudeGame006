# キャラ画像の作り方（ChatGPT）

キャラクターシート（設定画）をもとに、ChatGPT の画像生成でこのゲーム用の立ち絵を作るためのプロンプト集です。
1回の依頼で **全身の立ち絵** と **バストアップ** の2枚を作ります（表情差分は作りません）。

> ⚠ **使う前に必ず確認してください**
> - キャラクターシートや原作のキャラクターを AI で画像にすること、その画像をゲームで使うことについて、**原作者（権利者）の許可** を得てください
> - 他の作家・作品の絵柄をまねる指定（「〇〇先生風」など）はしないでください
> - 生成した画像は、公開前に原作者に確認してもらうと安心です

---

## 1. 準備するもの

- キャラクターシートの画像（正面の全身が描かれているものが一番よい）
- キャラクターの簡単な説明（名前・年齢・性格・服装など。シートに書いてあれば不要）

---

## 2. プロンプト（コピーして使う）

ChatGPT に **キャラクターシートの画像を添付** し、下のプロンプトを貼り付けて送ります。
書き換えるのは、一番上の **【入力】の1行だけ** です（特になければ「なし」のままで構いません）。

```
【入力】
- キャラクターの補足：【なし】

添付したキャラクターシートのキャラクターを、スマホ向けビジュアルノベルゲームの立ち絵として描いてください。
次の2枚を、1枚ずつ続けて生成してください。【入力】の補足があれば、表情や雰囲気の参考にしてください。

【共通の条件】
- キャラクターシートの顔立ち・髪型・髪色・目の色・服装・小物・配色を、細部まで正確に再現する
- 表情：穏やかな通常の表情（口は閉じるか、軽くほほえむ程度）
- 向き：正面、または体をわずかに斜めに向けた自然な立ち姿
- ポーズ：両腕を自然に下ろすなど、動きの少ない落ち着いたポーズ
- 画風：日本のアニメ・ギャルゲー風のセル塗り。輪郭線ははっきり、影は控えめ
- 光：正面からの均一な明るい光（強い逆光・色付きの光・影の落ち込みは避ける）
- 背景：完全に透明。床・影・地面・背景の模様は描かない
- キャラクター以外のものを入れない（文字・ロゴ・サイン・枠線・説明書き・カラーパレット・複数のポーズは不要）
- キャラクターは画像の左右中央に配置する
- 長い髪・広がったスカート・袖なども含めて、キャラクターのどの部分も画像の左右の端で切れないようにする（左右に少し余白を残す）

【1枚目：全身の立ち絵】
- 縦長の画像（縦横比 2:3、例：1024×1536）
- 頭のてっぺんから足先まで全身を入れる。どこも画像の外にはみ出さない
- 上と下に少しだけ余白を残す（足先の下は少しだけ）
- 体が画像の高さいっぱいに大きく入るようにする

【2枚目：バストアップ（腰から上）】
- 1枚目と同じキャラクター・同じ服装・同じ画風・同じポーズで描く
- 縦長の画像（縦横比 2:3、例：1024×1536）
- 頭のてっぺんから腰（おへそのあたり）までを、画像の高さいっぱいに大きく描く
- 画像の一番下の辺で、体が腰の位置で水平にまっすぐ切れるようにする（腰から下は画像の外。下に余白を作らない）
- 頭の上にはほんの少しだけ余白を残す
- 肩と腕は左右とも画像の中に収める（左右の端で切れないようにする）

【出力形式】
- 2枚とも生成できたら、透明な背景を保ったまま WebP 形式（品質 90 程度）に変換して、ダウンロードできるようにしてください
- ファイル名は、全身を「full.webp」、バストアップを「bust.webp」にしてください
- WebP に変換できない場合は、透明な背景の PNG のままで構いません
```

> 💡 2枚を1回で作ってくれない場合は、1枚目ができたあとに「続けて2枚目をお願いします」と送ってください。
>
> 💡 WebP への変換は、ChatGPT がファイルを作る機能を使って行います。利用状況によっては変換されず PNG のまま渡されることがあります。その場合は「この2枚を、透明な背景を保ったまま WebP に変換してダウンロードできるようにしてください」と送るか、[WebP 変換ツール](https://caitakenchikuclub.github.io/ClaudeGame006/tools/webp-converter.html) で変換してください。

## 3. うまくいかないときの追加の指示

生成された画像を見て、気になるところがあれば、同じ会話の中で次のように送ると直してもらえます。

| うまくいかないこと | 送る文章の例 |
|---|---|
| 背景が透明になっていない | `背景を完全に透明（透過PNG）にして、キャラクターはそのままでもう一度出力してください` |
| 顔や服装がシートと違う | `キャラクターシートと比べて【髪の長さ・リボンの色】が違います。シートどおりに直してください` |
| 足や頭が画像からはみ出している | `頭のてっぺんから足先まで全身が画像の中に収まるように、少し引いて描き直してください` |
| バストアップの下に余白がある | `体の下側が画像の一番下の辺でまっすぐ切れるように、下の余白をなくして描き直してください` |
| バストアップが胸までしかない／足まである | `頭のてっぺんから腰（おへそのあたり）までが、画像の高さいっぱいに入るように描き直してください` |
| 髪やスカートが左右の端で切れている | `髪やスカートも含めて、左右の端で切れないように、少しだけ引いて描き直してください` |
| バストアップの肩や腕が左右で切れている | `肩と腕が左右とも画像の中に収まるように、少しだけ引いて描き直してください（腰から上の範囲はそのまま）` |
| 文字や枠、パレットが入っている | `文字・枠線・カラーパレットなど、キャラクター以外のものをすべて消してください` |
| 影や床が描かれている | `足元の影と床を消して、キャラクターだけにしてください` |
| 1枚目と2枚目で別人に見える | `2枚目の顔・髪型・配色を、1枚目と完全に同じにしてください` |
| 表情が大げさ | `表情をもっと穏やかな通常の表情にしてください` |

## 4. 画像を仕上げる

1. **背景が透明かを確認する**
   ChatGPT の画面では透明な部分が白や市松模様に見えることがあります。ダウンロードした画像を、画像ビューアやゲーム画面で確認してください。
   どうしても透明にならないときは、背景削除ツール（画像編集アプリの「背景を削除」機能など）で背景を消してください。
2. **ファイル名について**
   全身は `full.webp`、バストアップは `bust.webp` という名前でダウンロードされます。
   [画像登録ボタン](作品の追加方法.md) を使う場合は、正しいファイル名を自動で付けるので、このままアップロードして構いません。
   手作業で登録する場合は、半角英数字の名前に付け直してください（例：全身 `sakura.webp`／バストアップ `sakura_bust.webp`）
3. **WebP 形式か確認する（おすすめ）**
   プロンプトで WebP への変換も頼んでいますが、PNG のまま渡された場合は [WebP 変換ツール](https://caitakenchikuclub.github.io/ClaudeGame006/tools/webp-converter.html) で変換してください（透明な部分はそのまま残ります）。
   ファイルが小さくなり、ゲームの読み込みが速くなります。PNG のままでも使えます。
   変換すると透明部分が消える設定のツールもあるので、変換後に透明が残っているか確認してください。
4. 作品フォルダの `characters/` に入れる

## 5. ゲームに登録する

> 💡 **画像登録ボタンを使うと簡単です**：`uploads` フォルダに画像をアップロードし、Actions タブの「画像を登録する」を実行すると、WebP への変換・置き場所・設定ファイルへの反映がまとめて行われます（[作品の追加方法](作品の追加方法.md) の「画像登録ボタン」）。以下は手作業で登録する場合の説明です。

`characters.json`（[設定ファイル作成ツール](https://caitakenchikuclub.github.io/ClaudeGame006/tools/json-generator.html) で作れます）に、1人のキャラクターとして2枚とも登録します。
**このプロンプトで作った画像なら、大きさや位置の数値を書く必要はありません。**

```json
{ "id": "sakura", "name": "サクラ", "image": "sakura_bust.webp", "full": "sakura.webp" }
```

| 項目 | 内容 |
|---|---|
| `image` | バストアップ（腰から上）の画像。ふだんの立ち絵になります |
| `full` | 全身の画像（なくても可） |

シナリオでは、キャラ名の後ろに「全身」を付けると全身、付けなければバストアップで表示されます。

```
#キャラ画像右 サクラ

#台詞 サクラ
「ちょっと聞いてよ！」

#キャラ画像右 サクラ 全身

#モノローグ
　サクラはくるりと回ってみせた。
```

- 同じ位置でバストアップ ⇔ 全身を切り替えると、そのまま入れ替わります
- 表情差分（`expressions`）は、バストアップにだけ使われます
- 全身だけを使うキャラは、`full` だけを書けば `#キャラ画像 サクラ` でも全身が表示されます

### 大きさの初期値

| 画像 | 大きさ（画面の高さに対する%） |
|---|---|
| バストアップ（`image`） | **75** |
| 全身（`full`） | **85** |

どうしても調整したいときだけ、`height`（大きさ）や `offsetY`（縦の位置。マイナスで上へ）を書きます。
全身の大きさを変えたいときは `"full": { "image": "sakura.webp", "height": 90 }` のように書きます。

## 6. ゲーム画面での見え方のしくみ（参考）

- 立ち絵は **画面の下端に合わせて** 表示され、大きさに合わせて縮小・拡大されます（縦横比はそのまま）
- 画面の下から約1/4はメッセージウィンドウに隠れます。そのため、
  - バストアップは **腰まで** 描いておくと、腰のあたりがウィンドウの裏に隠れ、顔が画面の真ん中より少し上に来ます（胸までの画像だと、顔が下がりすぎます）
  - 全身の立ち絵は、足元が見えなくても問題ありません
- 画像の下端は体の途中でまっすぐ切れているのが理想です。下に余白があると、体が宙に浮いて見えます
- 髪などが画像の左右の端で切れている絵でも、切れ目が目立たないよう、立ち絵の左右の端は少しぼかして表示します（それでも気になるときは、左右に余白のある画像に描き直してもらってください）
- キャラクターの左右の余白は表示位置に影響します。左右中央に配置した画像を使ってください。ずれる場合は `offsetX` で調整できます
- 以前の「胸の下まで」のバストアップ画像を使う場合は、`"height": 65, "offsetY": -12` 程度を書くと、同じような見え方になります
