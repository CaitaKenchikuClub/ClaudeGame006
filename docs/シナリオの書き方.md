# シナリオの書き方

このゲームのシナリオは、**普通のテキストファイル（.txt）** に、日本語のコマンドと文章を書くだけで作れます。
プログラミングの知識は必要ありません。

> 💡 **シナリオエディタ**：https://caitakenchikuclub.github.io/ClaudeGame006/tools/scenario-editor.html
> ボタンを押すとコマンドが入るエディタです。作品を選ぶと、登録済みのキャラ名・背景名などをボタンで選べます。
> 書き終えたら「ダウンロード」で .txt ファイルとして保存し、作品の `scenarios` フォルダに入れてください。
> （入力内容はブラウザに自動保存されます。今あるシナリオは「ファイルを開く」で読み込めます）

---

## 1. いちばん簡単な例

```
#背景 教室

#キャラ画像 サクラ

#台詞 サクラ
「どうしたの？」

#モノローグ
　今日はいい天気だ。

#終了
```

これだけで、

1. 教室の背景が表示され
2. サクラの立ち絵が真ん中に出て
3. 名前「サクラ」付きで「どうしたの？」と表示され
4. 名前なしで「今日はいい天気だ。」と表示され
5. 読了画面に進みます

画面をタップするたびに、文章が1つずつ進みます。

---

## 2. ファイルの準備

- シナリオは作品フォルダの中の `scenarios` フォルダに入れます（例：`public/stories/novel_001/scenarios/episode_01.txt`）
- 文字コードは **UTF-8** で保存してください（メモ帳・VS Code・テキストエディットなど、最近のエディタは通常 UTF-8 です）
- ファイル名は半角英数字にしてください（例：`episode_01.txt`、`episode_02.txt`）
- 作ったファイルは、作品の `info.json` の `episodes` に登録します（[作品の追加方法](作品の追加方法.md) を参照）

---

## 3. コマンド一覧

`#` で始まる行がコマンドです。`#` は全角の `＃` でも大丈夫です。
コマンドと名前の間は、半角スペースでも全角スペースでも構いません。

### 文章を表示する

| コマンド | 意味 |
|---|---|
| `#台詞 キャラ名` | 次の行からの文章を、そのキャラのセリフとして表示します。名前がメッセージウィンドウに出ます |
| `#モノローグ` | 次の行からの文章を、名前なしの地の文として表示します |

```
#台詞 ルリ
「……ちょっと、話があるんだけど」

#モノローグ
　ルリはそれきり黙ってしまった。
```

- 「」はゲームが自動で付けません。セリフには自由に「」『』（）などを書いてください
- `#台詞` の名前は、立ち絵が登録されていない名前でも使えます（例：`#台詞 店員`、`#台詞 ？？？`）

### 背景・スチル

| コマンド | 意味 |
|---|---|
| `#背景 背景名` | 背景を切り替えます |
| `#スチル スチル名` | 一枚絵（スチル）を表示します。表示中は立ち絵が隠れます |
| `#スチル なし` | スチルを消して、元の背景と立ち絵に戻します |

背景名・スチル名は、作品の `assets.json` に登録した名前を書きます。

### キャラクターの立ち絵

| コマンド | 意味 |
|---|---|
| `#キャラ画像 キャラ名` | 立ち絵を **真ん中** に表示します |
| `#キャラ画像左 キャラ名` | 立ち絵を **左** に表示します |
| `#キャラ画像右 キャラ名` | 立ち絵を **右** に表示します |
| `#キャラ画像 なし` | **すべての** 立ち絵を消します |
| `#キャラ画像左 なし` | 左の立ち絵だけ消します |
| `#キャラ画像右 なし` | 右の立ち絵だけ消します |
| `#表情 キャラ名 表情名` | 立ち絵の表情を変えます |
| `#表情 キャラ名 なし` | 表情を通常の画像に戻します |

```
#キャラ画像右 サクラ
#キャラ画像左 ルリ

#表情 サクラ 笑顔
```

- 同じキャラを別の位置に指定すると、そのキャラが **移動** します（2人に増えることはありません）
- 立ち絵は最大3人（左・真ん中・右）まで同時に表示できます
- 表情は、一度変えると `#表情 キャラ名 なし` で戻すまでそのままです
- キャラ名・表情名は、作品の `characters.json` に登録した名前を書きます
- 立ち絵の大きさや位置は `characters.json` で設定します。シナリオに書く必要はありません

### 音

| コマンド | 意味 |
|---|---|
| `#BGM 曲名` | BGM を流します。場面が変わっても流れ続けます |
| `#BGM なし` | BGM を止めます |
| `#効果音 音名` | 効果音を1回鳴らします |

曲名・音名は、作品の `assets.json` に登録した名前を書きます。
BGM はエピソードが終わると自動的に止まります。

### 終わり

| コマンド | 意味 |
|---|---|
| `#終了` | エピソードを終えて、読了画面に進みます |

`#終了` を書き忘れても、ファイルの最後まで読むと読了画面に進みます。

## 4. 文章のルール

### 1回のタップで表示される範囲

コマンドの後ろの文章は、**次のコマンドまでが1つの文章** として、1回のタップで表示されます。
途中の空行もそのまま表示されます。

```
#モノローグ
　ルリはそれきり黙ってしまった。

　窓の外では、運動部のかけ声が遠くに聞こえる。
```

↑ この3行（空行を含む）は、1回のタップでまとめて表示されます。
文章を分けて表示したいときは、もう一度 `#モノローグ` や `#台詞` を書いてください。

```
#モノローグ
　ルリはそれきり黙ってしまった。

#モノローグ
　窓の外では、運動部のかけ声が遠くに聞こえる。
```

↑ こちらは2回のタップで1つずつ表示されます。

> 💡 1つの文章が長すぎると、スマホではメッセージウィンドウに入りきらずスクロールが必要になります。
> **1回に表示する文章は4〜5行程度まで** が読みやすい目安です。

### コマンドなしで書いた文章

コマンドを書かずに書いた文章は、**地の文（名前なし）** になります。

```
#背景 廊下

気がつくと、廊下は夕焼けの色に染まっていた。
```

### 字下げ

行頭の全角スペース（字下げ）は、そのまま表示されます。

### `#` を文章として書きたいとき

- 文の途中の `#` は、そのまま文字として表示されます（例：`今日の #話題 は`）
- **行の先頭に** `#` を書きたいときは、前に `\` を付けて `\#` と書きます（全角の `＼＃` や `￥#` でも可）

```
#モノローグ
　黒板の隅には、誰かの落書きが残っていた。
\#今日の日直　サクラ
```

↑ 2行目は「#今日の日直　サクラ」と表示されます。

## 5. 書き間違えたとき

次のような書き間違いは、ゲーム画面の上部と公開前チェック（GitHub の Actions）に、**何行目に何があるか** が日本語で表示されます。

| 表示されるメッセージの例 | 原因と直し方 |
|---|---|
| `「#背影」は知らないコマンドです` | コマンド名の書き間違い。`#背景` に直す |
| `キャラ「ミナ」は characters.json に登録されていません` | キャラ名の書き間違いか、`characters.json` への登録忘れ |
| `表情「泣き」は … expressions に登録されていません` | 表情名の書き間違いか、`expressions` への登録忘れ |
| `背景「校庭」は assets.json の backgrounds に登録されていません` | 背景名の書き間違いか、`assets.json` への登録忘れ（スチル・BGM・効果音も同様） |
| `このコマンドの後に文章がありません` | `#台詞` や `#モノローグ` の後に文章を書き忘れている |
| `#背景 の後に背景名を書いてください` | コマンドの後ろの名前を書き忘れている |

問題があるまま `main` に送ると、公開は自動的に止まり、前の正しい状態のまま公開が続きます。

## 6. 完成例

```
#背景 教室
#BGM 日常
#効果音 チャイム

#モノローグ
　放課後の教室。窓から差し込む光が、机の上でまどろんでいる。

#キャラ画像 サクラ

#台詞 サクラ
「あれ？　まだ誰か残ってたんだ」

#キャラ画像右 サクラ
#キャラ画像左 ルリ

#台詞 ルリ
「……ちょっと、話があるんだけど」

#表情 サクラ 笑顔

#台詞 サクラ
「話？　わたしに？」

#キャラ画像 なし
#BGM なし
#スチル 夕焼け

#モノローグ
　私たちは、沈んでいく夕日を見つめていた。

#スチル なし
#キャラ画像 ルリ

#台詞 ルリ
「明日、また話す。……約束」

#終了
```
