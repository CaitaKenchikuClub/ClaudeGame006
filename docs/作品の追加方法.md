# 作品の追加方法

新しい作品やエピソードは、**ゲーム本体のプログラムを触らずに** 追加できます。
必要なのは「フォルダを作る → 素材を入れる → 設定ファイルを書く → シナリオを書く → 一覧に登録する」だけです。

シナリオの書き方は [シナリオの書き方](シナリオの書き方.md) を見てください。

---

## 全体の流れ

1. ひな形フォルダをコピーして、作品フォルダを作る
2. 画像・音声を入れる
3. 作品情報（`info.json`）を書く
4. キャラクター情報（`characters.json`）と素材の名前（`assets.json`）を書く
5. シナリオ（`.txt`）を書く
6. 作品一覧（`catalog.json`）に登録する
7. GitHub の `main` に送る → 自動でチェック・公開される

---

## 1. 作品フォルダを作る

`templates/story_template` フォルダを丸ごとコピーして、`public/stories` の中に置きます。
フォルダ名は **作品ID** になります。半角英数字と `_` で付けてください（例：`novel_003`）。

```
public/stories/
  catalog.json          … 作品一覧
  novel_001/            … サンプル作品
  novel_002/            … サンプル作品
  novel_003/            … ← 新しく作ったフォルダ
    info.json           … 作品情報
    characters.json     … キャラクター情報
    assets.json         … 背景・スチル・音の名前とファイルの対応
    cover.webp          … 表紙画像
    scenarios/          … シナリオ（.txt）
    backgrounds/        … 背景画像
    characters/         … 立ち絵画像
    stills/             … スチル画像
    audio/              … BGM・効果音
```

> 作品ごとにフォルダが分かれているので、ほかの作品の素材と混ざることはありません。

---

## 2. 画像・音声を入れる

| 種類 | 入れる場所 | おすすめの形式・大きさ |
|---|---|---|
| 表紙 | 作品フォルダの直下 | 縦長（5:7 程度、例：600×840px） |
| 背景 | `backgrounds/` | **縦長 9:16**（例：1080×1920px）。横長の画像は左右が切れて表示されます |
| 立ち絵 | `characters/` | **背景が透明な PNG または WebP**。全身でもバストアップでも可。高さ 1600px 程度まで |
| スチル | `stills/` | 縦長がおすすめ。横長の場合は上下に黒い帯が付いて全体が表示されます |
| BGM・効果音 | `audio/` | **mp3** がおすすめ（iPhone を含むほぼすべての端末で再生できます） |

- **ファイル名は半角英数字** にしてください（例：`sakura_smile.webp`）。日本語のファイル名は避けてください
- 画像は **WebP 形式** にするとファイルが小さくなり、読み込みが速くなります
- 1枚あたり **500KB 以下** が目安です（スマホの回線でも待たずに読めます）
- 他の人が作った画像・音声は、必ず権利者の許可を得てから使ってください

## 3. 作品情報（info.json）

```json
{
  "id": "novel_003",
  "title": "作品タイトル",
  "author": "作者名",
  "cover": "cover.webp",
  "summary": "作品一覧に表示する短い紹介文",
  "synopsis": "作品詳細に表示するあらすじ。\n改行したいところには \\n を書きます。",
  "genre": "ファンタジー",
  "originalUrl": "https://原作掲載ページのURL",
  "episodes": [
    { "id": "episode_01", "title": "第1話 タイトル", "file": "episode_01.txt", "order": 1 },
    { "id": "episode_02", "title": "第2話 タイトル", "file": "episode_02.txt", "order": 2 }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `id` | **フォルダ名と同じ** にします |
| `title` / `author` / `genre` | 作品タイトル・作者名・ジャンル |
| `cover` | 表紙画像のファイル名 |
| `summary` | 作品一覧のカードに出る短い紹介文 |
| `synopsis` | 作品詳細に出るあらすじ。改行は `\n` |
| `originalUrl` | 「原作を読む」「原作の続きを読む」ボタンのリンク先。`https://` から始めます |
| `episodes` | エピソードの一覧（下を参照） |

エピソードの項目：

| 項目 | 内容 |
|---|---|
| `id` | エピソードの識別名（半角英数字）。**公開後は変えない** でください（読了記録・続きからの位置がリセットされます） |
| `title` | 画面に表示するエピソード名 |
| `file` | `scenarios` フォルダに入れたシナリオのファイル名 |
| `order` | 表示順。小さい数字から順に並びます |

> ⚠ JSON の書き方の注意：文字は `"` で囲む／項目の間は `,` で区切る／**最後の項目の後ろには `,` を付けない**。
> 書き間違えると、公開前チェックで「JSON の書き方に誤りがあります」と表示されます。

---

## 4. キャラクター情報（characters.json）

```json
{
  "characters": [
    {
      "id": "sakura",
      "name": "サクラ",
      "image": "sakura.webp",
      "expressions": {
        "笑顔": "sakura_smile.webp",
        "怒り": "sakura_angry.webp"
      },
      "height": 85
    },
    { "id": "ruri", "name": "ルリ", "image": "ruri_bust.webp", "height": 55 }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `id` | 半角英数字の識別名 |
| `name` | シナリオで使う名前（例：`#キャラ画像 サクラ`） |
| `image` | ふだんの立ち絵の画像ファイル名（`characters/` フォルダ内） |
| `expressions` | 表情差分（なくても可）。左が表情名（例：`#表情 サクラ 笑顔`）、右が画像ファイル名。表情名は自由に付けられます |
| `height` | 画面の高さに対する立ち絵の高さ（%）。省略すると 85。**全身なら 80〜90、バストアップなら 50〜60** が目安 |
| `offsetX` | 横の位置の微調整（%）。プラスで右、マイナスで左へずれます。省略可 |
| `offsetY` | 縦の位置の微調整（%）。プラスで下、マイナスで上へずれます。省略可 |

> 表情差分の画像は、ふだんの立ち絵と **同じ大きさ・同じ位置** で作ると、切り替えたときにずれません。

---

## 5. 素材の名前（assets.json）

シナリオで使う「名前」と、実際の「ファイル名」の対応を書きます。

```json
{
  "backgrounds": {
    "教室": "classroom.webp",
    "廊下": "corridor.webp"
  },
  "stills": {
    "夕焼け": "sunset.webp"
  },
  "bgm": {
    "日常": "daily.mp3"
  },
  "se": {
    "ドア": "door.mp3"
  }
}
```

| 項目 | 使うコマンド | ファイルの場所 |
|---|---|---|
| `backgrounds` | `#背景 教室` | `backgrounds/` |
| `stills` | `#スチル 夕焼け` | `stills/` |
| `bgm` | `#BGM 日常` | `audio/` |
| `se` | `#効果音 ドア` | `audio/` |

使わない項目は `{}` のままで構いません。

---

## 6. シナリオを書く

`scenarios` フォルダに `.txt` ファイルを作り、[シナリオの書き方](シナリオの書き方.md) に沿って書きます。
ファイル名は `info.json` の `episodes` の `file` と同じにします。

---

## 7. 作品一覧に登録する（catalog.json）

`public/stories/catalog.json` の `stories` に、作品ID を追加します。
**ここに書いた順番で作品一覧に並びます。**

```json
{
  "stories": ["novel_001", "novel_002", "novel_003"]
}
```

> 一時的に作品を非公開にしたいときは、ここから作品ID を消すだけで一覧に出なくなります（フォルダは残したままで大丈夫です）。

---

## 8. 公開する

`main` ブランチに送ると、GitHub が自動で次のことを行います（数分かかります）。

1. 全作品のシナリオ・設定・素材をチェック
2. 問題がなければゲームを組み立てて公開

### GitHub のサイトだけで作業する場合

1. リポジトリのページで公開したいフォルダ（例：`public/stories`）を開く
2. **Add file → Upload files** を選び、作品フォルダやファイルをドラッグ＆ドロップ
3. 画面下の **Commit changes** を押す（「Commit directly to the `main` branch」を選んだまま）
4. 既存のファイル（`catalog.json` など）を直すときは、ファイルを開いて右上の ✏️（鉛筆）ボタンで編集し、**Commit changes** を押す

### 公開結果の確認

- リポジトリの **Actions** タブを開くと、公開処理の状況が見られます
- 🟢 緑のチェック：公開完了。数分後にゲームに反映されます
- 🔴 赤い ×：問題があり、公開が止まっています。クリックして開き、`build` → `Run npm run build` の中に、**どのファイルの何行目に何の問題があるか** が日本語で表示されています。直してもう一度送ってください

> 問題があるときは公開が止まるので、壊れたシナリオがプレイヤーに届くことはありません（前の正しい状態のまま公開が続きます）。

---

## エピソードだけを追加するとき

1. `scenarios` フォルダにシナリオ（例：`episode_03.txt`）を入れる
2. 新しく使う画像・音声があれば入れて、`characters.json` / `assets.json` に登録する
3. `info.json` の `episodes` に1行追加する

```json
    { "id": "episode_03", "title": "第3話 タイトル", "file": "episode_03.txt", "order": 3 }
```

（すぐ上の行の最後に `,` を付けるのを忘れずに）

---

## 自分のパソコンで確認したいとき（任意）

Node.js をインストールしたパソコンでは、公開前に手元で確認できます。

```bash
npm install      # 初回のみ
npm run check    # 全作品のチェック
npm run dev      # ゲームを起動（表示された URL をブラウザで開く）
```
